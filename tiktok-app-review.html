Public service information

Manage social publishing from one organised workspace.

Multi Post is a web-based social media management service for agencies, businesses and content teams. The workspace opens directly. Users then choose which social platform to connect, authorise access through that platform's official OAuth flow, prepare content and explicitly choose when and where each post is published.

How the TikTok integration works

Multi Post uses TikTok's OAuth/Login Kit authorisation and Content Posting API only after the TikTok account owner chooses to connect TikTok and approves the requested permissions.

Open a workspaceNo separate Multipost login is required before viewing the workspace.
Connect TikTokThe user clicks the TikTok connection control, is sent to TikTok's official authorisation screen and reviews the requested permissions.
Identify the destinationMulti Post displays the authorised TikTok profile so the user can confirm the correct account.
Prepare the postThe user selects a local video, writes or edits the caption and chooses an available privacy setting.
Publish with explicit consentNothing is posted automatically. The transfer begins only when the user clicks “Publish to TikTok.”
Confirm completionMulti Post checks the publishing status and displays the result to the user.
TikTok permissions used by the service are limited to the functionality requested for basic authorised profile identification and user-initiated video upload/publishing. Multi Post does not post in the background and does not sell TikTok account data.

Privacy, security and user control

Clear consent

TikTok is connected only through TikTok's official authorisation screen after the user chooses to connect it.

Reversible access

Users can remove a connected TikTok account from their Multi Post workspace and can revoke permissions from TikTok.
